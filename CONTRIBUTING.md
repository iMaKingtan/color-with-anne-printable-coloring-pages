# Contributing

This repository is a reviewed preview catalog maintained by Color with Anne.
Small corrections and accessibility improvements are welcome.

## Good contributions

- Fixing accessibility, printing, or responsive-layout problems
- Improving the metadata schema or documentation
- Correcting inaccurate or unclear instructions

New artwork is added by the Color with Anne maintainer so that authorship and
licensing remain unambiguous. Please do not submit copyrighted characters,
logos, celebrity likenesses, traced artwork, scraped files, or bulk-generated
collections.

## Adding a theme

1. Use only original artwork owned by Color with Anne.
2. Create a dedicated topic page on `colorwithanne.com` as the official source.
3. Add branded WebP previews, not print-quality PDFs.
4. Place files in `docs/assets/coloring-pages/<theme-slug>/`.
5. Add complete records to `catalog/coloring-pages.json`.
6. Provide specific, natural titles and alt text for every scene.
7. Test the gallery on desktop and mobile before publishing.

## Editorial review

Every addition should answer three questions:

- Is it genuinely useful to a parent, teacher, or child?
- Is its official source and license unambiguous?
- Does it add something distinct rather than a near-duplicate?

Small, thoughtful pull requests are easiest to review.
